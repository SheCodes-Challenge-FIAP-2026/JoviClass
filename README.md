Seja bem vindo ao JoviClass - Projeto Acadêmico da FIAP

Para melhor experiência dentro do nosso projeto, solicitamos que rode o arquivo "camera.html" em uma página web e assim que a mesma abrir opte pela versão mobile. 
O fluxo acontece da seguinte forma (neste momento apresentamos apenas a interface por isso algumas funcionalidades estarão presentes posteriormente):
1. Execute o código para visualizar seu resultado em uma página web (camera.html)
2. Clique no ícone JoviClass.
3. Selecione sua matéria - sessão inicia.
4. Clique no botão verde no canto inferior direito para finalizar.
5. Analise suas possibilidade e salve o arquivo. Neste momento essa ação te levará ao nosso app, porém no contexto da proposta final, o usuário irá permanecer na câmera para repetir o fluxo quantas vezes quiser.
6. Você também tem a opção de abrir o app ao clicar no botão correspondente a essa ação que fica em baixo da última matéria pré-definida.
7. Fique a vontade para navegar em nossa interface.
